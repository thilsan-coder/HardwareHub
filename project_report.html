1 Executive Summary & Architecture

This project implements an enterprise-grade Product & Inventory Suite in exact compliance with the assessment guidelines. It connects a high-performance Laravel 12 REST API Gateway, a responsive React Web Portal, and a production-grade Flutter Mobile App equipped with an automatic multi-URL fallback engine for zero-config physical device connectivity.

⚡ Laravel 12 Backend
Sanctum Token Authentication, RESTful endpoints, soft delete recovery, and transactional stock calculation.
💻 React 18 Web App
Tailwind CSS dark-header tokens, real-time KPI metrics, Product CRUD, and one-click CSV/PDF export.
📱 Flutter Mobile App
Custom Slate/Indigo design tokens, unblocked inline subheader action pills, and auto-detect USB/LAN engine.

4 Step-by-Step Execution Guide

🔑 Default Admin Credentials: Email: admin@hardwarehub.com  |  Password: password

Step 1: Database & Backend Server

1. Start MySQL in XAMPP (Port 3306).

2. Open Terminal 1 and start Laravel server:

cd d:\HardwareHub\hardwarehub-backend
php artisan serve --host 0.0.0.0 --port 8000

Step 2: React Web Frontend

1. Open Terminal 2 and start Vite server:

cd d:\HardwareHub\hardwarehub-backend
npm run dev

2. Open browser: http://localhost:5173

Step 3: Flutter Mobile Application

Connect your Android phone (Samsung Galaxy A05s) via USB or Wi-Fi, then run:

& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" reverse tcp:8000 tcp:8000
cd d:\HardwareHub\hardwarehub_mobile
flutter run -d R7AW903PBSM

* Note: The app automatically detects USB mode (127.0.0.1:8000) and Wi-Fi mode (192.168.1.3:8000) via its built-in Auto-Fallback Engine.
